# 🎓 Department Management System (Java OOP)

A console-based academic management application built with Java and Object-Oriented Programming (OOP) principles. The system manages students, teachers, courses, and grade evaluation through a structured menu-driven interface.

This project demonstrates practical implementation of core OOP concepts including encapsulation, inheritance, abstraction, interfaces, and aggregation while modeling a real-world university department environment.

---

## ✨ Features

### 👨‍🎓 Student Management

* Register and store student records
* Search students by ID
* View student information
* Organize academic records efficiently

### 👨‍🏫 Teacher Management

* Manage teacher profiles
* Store and maintain teacher information

### 📚 Course Management

* Maintain department course listings
* Organize course information

### 📊 Grade Evaluation System

Weighted grading calculation:

* Mid Exam → 30%
* Project → 30%
* Final Exam → 40%

The system automatically calculates final student scores using the weighted grading model.

### ⚙️ System Features

* Interactive menu-driven console interface
* Input validation for user entries
* Structured navigation system
* Simple and maintainable architecture

Final Score Calculation:

## ▶️ Getting Started

### Prerequisites

* Java JDK 8 or higher
* IntelliJ IDEA, Eclipse, NetBeans, or any Java IDE

### Installation

Clone the repository:

```bash
git clone https://github.com/gemachistesfaye/department-management-system.git
```

Navigate to the project directory:

```bash
cd department-management-system
```

Compile the project:

```bash
javac *.java
```

Run the application:

```bash
java Test
```
