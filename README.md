# 🎓 Department Management System (Java OOP)

## 📌 Overview
The **Department Management System** is a console-based Java application built using Object-Oriented Programming (OOP) principles. It simulates an academic management system for handling students, teachers, courses and grade evaluation in a structured and scalable way.

This project demonstrates real-world system modeling using clean architecture and core Java concepts.

---

## ✨ Features

### 👨‍🎓 Student Management
- Register and manage student records  
- Search student by ID  
- Store and organize student information  

### 👨‍🏫 Teacher Management
- Maintain teacher profiles and details  

### 📚 Course Management
- List and organize available courses  

### 📊 Grade Evaluation System
Weighted grading model:
- Mid Exam → 30%  
- Project → 30%  
- Final Exam → 40%  

### ⚙️ System Features
- Menu-driven console interface  
- Input validation (numbers & strings)  
- Clean and structured navigation system

## 🏗️ Project Structure

| File | Description |
|------|-------------|
| Person.java | Base class containing shared attributes |
| Student.java | Extends Person and handles student logic |
| Address.java | Aggregation class for address details |
| Department.java | Interface defining system structure |
| Test.java | Main class (menu system & execution) |

---

## 📊 Grading System

Student performance is calculated using a weighted evaluation model:

Final Score = (Mid Exam × 30%) + (Project × 30%) + (Final Exam × 40%)

## ▶️ How to Run the Project

### 📌 Prerequisites
- Java JDK 8 or higher  
- IDE (NetBeans / IntelliJ IDEA / Eclipse)

### 🚀 Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/gemachistesfaye/department-management-system.git
   ```

3. Open the project in your IDE  
4. Navigate to Test.java  
5. Run the file  
6. Follow the console menu instructions
