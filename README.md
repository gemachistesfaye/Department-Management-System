# 🎓 Department Management System (Java OOP)

## 📌 Project Overview
The **Department Management System** is a console-based application developed using Java Object-Oriented Programming principles. It simulates an academic management system for handling students, teachers, courses, and grade evaluation.

This project demonstrates structured software design, OOP principles, and real-world academic system modeling.

---

## ⚙️ Features
- Student registration and management
- Teacher information handling
- Course listing system
- Search student by ID
- Grade calculation system (Weighted model)
  - Mid Exam: 30%
  - Project: 30%
  - Final Exam: 40%
- Input validation (numbers and strings)
- Menu-driven console interface

---

## 🧠 Technologies & Concepts Used
- Java (Core Programming)
- Object-Oriented Programming (OOP)
  - Inheritance
  - Encapsulation
  - Interfaces
  - Aggregation
- ArrayList (Data storage)
- Scanner (User input handling)

---

## 🏗️ Project Structure
- `Person.java` → Base class (common attributes)
- `Student.java` → Extends Person (student logic)
- `Address.java` → Aggregation class (address details)
- `Department.java` → Interface (system structure)
- `Test.java` → Main class (menu system & execution)

---

## 📊 Grading System
Student performance is calculated using weighted evaluation:

- Mid Exam → 30%
- Project → 30%
- Final Exam → 40%

---

## ▶️ How to Run
1. Open project in **NetBeans / IntelliJ IDEA / Eclipse**
2. Run `Test.java`
3. Follow the console menu
