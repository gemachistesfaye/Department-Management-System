## ⚡ Quick Start

```bash
git clone https://github.com/gemachistesfaye/Department-Management-System.git
cd Department-Management-System
mkdir -p out
javac -d out *.java
java -cp out project1.Main
```

> **IDE users:** Open project → run `Main.java` → follow the console menu (1–7)
